# Gallocanta_rewetting
Rewetting experiment on long-term exposed sediments of Lake Gallocanta (Spain) to assess changes in microbial community composition.

# Code for CO2 influx and efflux circadian cycles in bare dry lake sediments

This repository contains the Jupyter Notebook and R scripts used for the data analysis and figure generation associated with the following manuscript:

**Manuscript:** CO2 influx and efflux circadian cycles in bare dry lake sediments  
**Journal:** *Biogeosciences*  
**Authors:** Ertürk Arı, P., Marcé, R., Sacristán-Soriano, O., Tolunay, D., Borrego, C.M., Poblador, S., Obrador, B., Moreno-Ostos, E., Montes Pérez, J. J., Conejo-Orosa, T., Koschorreck, M., Peñuelas, J., Catalán, N.  
**Status:** Under revision

## Repository contents

- `notebooks/`: Jupyter Notebook containing the associated sequence analyses.
- `scripts/`: R scripts used for data processing and analysis.

## Requirements

The analyses were performed using Python and R. The software versions and required packages are documented in the corresponding scripts and notebook.

## Reproducibility

The notebook and scripts are provided to document the analytical workflow and facilitate reproducibility of the results reported in the manuscript.

Before running the analyses, ensure that the required software and packages are installed and that the input data are available at the paths specified or configured in the code.

## Data availability

The input data used by the scripts are available at the NCBI Sequence Read Archive (SRA) database under the accession number PRJNA1090308.
